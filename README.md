# TechoraX Zone — 20 Content Edition

Responsive single-page facts and technology website with 20 short educational articles, search, topic filters, share button, and 10 labelled ad placeholders.

## Files
- `index.html` — content and 10 ad placement markers
- `style.css` — responsive layout
- `script.js` — topic filters, search, read-more controls, share button
- `README.md` — setup notes

## Add Adsterra ads
1. Sign in at https://publishers.adsterra.com/ and add your real, published website.
2. Follow the dashboard's current review and ad-unit setup process.
3. Use the exact ad code generated for your approved site and format. Replace the corresponding `<!-- ADSTERRA_CODE_n -->` marker with that code.
4. A placeholder is not an ad. Ads will not appear until valid provider code is inserted.
5. Don't copy someone else's code, duplicate a unit against provider instructions, ask visitors to click ads, or use bots/incentivized traffic. Keep Adult Ads disabled for this general-audience website.

## Free GitHub Pages hosting
1. Create a public repository named `TechoraX-Zone`.
2. Upload all four files to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL shown in Pages settings.
6. Add that exact published URL to your Adsterra publisher dashboard and follow its approval process.

GitHub Pages hosts static files. Check current Adsterra terms/support guidance to ensure your chosen ad format is compatible with your hosting and traffic sources.
